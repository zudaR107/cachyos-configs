## [1.0.0] - 2026-03-17

Initial public release of the repository.

### Added

* Curated configuration directories for:

  * Alacritty
  * Code - OSS
  * Fastfetch
  * Firefox
  * Fish
  * GTK 3
  * GTK 4
  * Niri
  * Noctalia
  * Qt5ct
  * Qt6ct
  * Starship
  * Vim
* Repository screenshots under `assets/screenshots/`
* GitHub issue templates
* GitHub pull request template
* GitHub Actions lint workflow for repository validation
* `.editorconfig` for formatting consistency
* `.gitattributes` for line ending normalization
* `.gitignore` for local artifacts and temporary files
* `scripts/bootstrap.sh` interactive setup helper
* `requirements.md` documenting expected runtime environment and dependencies
* `CONTRIBUTING.md` documenting contribution rules and repository scope
* `README.md` describing the repository structure, setup flow, screenshots, badges, and usage notes
